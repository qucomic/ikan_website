# ikan 静态官网实现计划

目标：参考 ESO 官网的信息结构，使用 ikan 品牌素材，制作独立、响应式产品官网。
技术：原生 HTML/CSS/JavaScript；无 CDN、无框架、无构建、无运行时 API。
用户确认：在 ikan_website 目录开发；设计由开发者决定。

- [x] 页面：品牌导航、首屏、功能、界面示意、下载、新手指南、规则手册、常见问题。
- [x] 交互：移动菜单、界面切换、下载配置、原生 FAQ 展开；支持键盘与减少动画。
- [x] 验证：静态资源与锚点检查、JS 语法、下载配置检查、桌面与移动浏览器预览。

设计：墨绿 #075744、金黄 #E6B84A、浅绿 #EAF3EE、白 #FFFFFF、正文 #203E35。
字体：本机中文无衬线与系统字体；标题大字号、左对齐；圆弧与书页构成主视觉。
边界：界面为产品能力示意；未提供的正式下载地址显示待发布，不伪造发行与平台状态。
部署：用户指定本地开发，不创建远端托管项目；任意静态服务器均可托管目录。

验证记录：全部 12 个 HTML 页面及内部链接/锚点通过；JS 语法通过；浏览器验证菜单与 Escape、三种界面切换、指南与规则页；375px/727px/1440px 布局已预览。727px 页面 scrollWidth 等于 viewport，无横向溢出。
