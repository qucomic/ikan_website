# Ikan App 普通用户操作手册

> 适用对象：只需要安装、导入内容源并使用 App 的普通用户。  
> 本手册不介绍规则编写、规则字段或调试方法。  
> 文档更新日期：2026-09-04

## 1. 使用前须知

Ikan App 通过“规则”连接不同的内容来源。安装 App 后，需要先导入规则或添加规则订阅，才能正常使用发现、搜索和阅读功能。

- **导入规则**：把当前收到的规则保存到本机。以后不会跟随发布者自动更新。
- **添加订阅**：保存一个远程订阅地址。以后可以手动刷新，也可以在启动 App 时自动刷新。
- 规则及订阅地址应从你信任的发布者处获取。
- 部分内容源可能因网络、网站改版或登录状态而暂时不可用，这不一定是 App 故障。
- 请遵守首次启动时显示的免责声明以及当地法律法规。

如果对方同时提供“规则文件”和“订阅地址”，一般优先选择**订阅地址**，后续维护更方便。

## 2. 安装 App

### 2.1 Android 安装

1. 从项目维护者或你信任的正式发布渠道下载 Android 安装包（APK）。
2. 在手机的“下载”或“文件管理”中找到 APK，点击打开。
3. 如果系统提示“不允许安装未知应用”，进入系统设置，临时允许当前浏览器或文件管理器安装应用。
4. 返回安装界面，点击“安装”。
5. 安装完成后，点击“打开”。

> 安全提示：不要安装来源不明、文件名异常或被他人重新打包的安装包。安装完成后，可按需关闭“安装未知应用”权限。

## 4. 添加内容源

首次使用时，可以选择“导入规则”或“添加订阅”。两者任选其一即可，也可以同时使用。

### 4.1 导入规则

#### 方法一：从“发现”页导入

1. 点击底部的“发现”。
2. 点击页面中的“导入规则”。
3. 根据你拿到的内容选择一种导入方式：
   - 点击“选择文件”，选择规则文件；
   - 将规则网址粘贴到输入框；
   - 粘贴 `ikan://` 或 `eso://` 开头的分享链接；
   - 直接粘贴规则提供者发来的规则内容。
4. 确认输入无误后，点击底部的“导入文件”“导入网址”或“导入规则”。按钮文字会根据输入内容自动变化。
5. 导入窗口关闭后，返回“发现”页查看新增的本地规则。

![截图：发现页的导入规则入口](images/user-guide/06-discover-import-entry.png)

*截图建议：用标记指出“发现”页中的“导入规则”按钮。*

![截图：导入规则窗口](images/user-guide/07-import-rule-dialog.png)

*截图建议：展示“选择文件”、输入框和底部导入按钮。*

#### 方法二：从“设置”页导入

1. 点击底部的“设置”。
2. 进入“规则管理”。
3. 点击右上角的“导入规则”图标。
4. 选择文件或粘贴规则内容，然后点击导入按钮。

![截图：规则管理页的导入入口](images/user-guide/08-source-management-import.png)

*截图建议：展示“设置 → 规则管理”页面，并标出右上角的导入按钮。*

#### 导入多个规则

规则文件可能包含一条或多条规则。选择文件后，窗口上方会显示类似“1/5”的数量提示，可以用“前”“后”查看文件中的不同规则；点击“导入文件”后会按文件内容一起导入。

“格式化”只用于整理输入框中的显示格式，不是导入必需步骤。“导出备份”用于备份当前已有规则，普通导入时不需要点击。

### 4.2 添加订阅

1. 点击底部的“发现”。
2. 点击“添加订阅”。
3. 在“订阅地址”中粘贴发布者提供的完整网址。
4. “订阅名称”可以不填；留空时 App 会根据地址自动生成名称。
5. 点击“添加”。
6. 等待提示“已添加 N 条规则”。如部分内容有问题，提示中可能会显示跳过的异常规则数量。

![截图：发现页的添加订阅入口](images/user-guide/09-add-subscription-entry.png)

*截图建议：标出“添加订阅”按钮。*

![截图：添加订阅窗口](images/user-guide/10-add-subscription-dialog.png)

*截图建议：展示“订阅地址”“订阅名称（选填）”和“添加”按钮。*

> 注意：订阅地址必须是规则发布者提供的远程订阅地址。普通网页地址、作品详情页地址或下载页地址通常不能作为订阅地址。

### 4.3 更新和管理订阅

在“发现”页找到“订阅规则”区域：

- 点击订阅右侧的刷新按钮，可立即更新该订阅。
- 点击更多菜单，可以“重命名订阅”“修改订阅地址”或“删除订阅”。
- 删除订阅时，该订阅带来的规则也会删除，但手动导入的本地规则不受影响。

![截图：订阅规则管理](images/user-guide/11-subscription-management.png)

*截图建议：展开一个订阅，展示刷新按钮和更多菜单。*

如需自动更新：

1. 进入“设置”。
2. 点击“订阅设置”。
3. 打开“启动时刷新订阅”。

启用后，App 会在首页显示后于后台更新全部订阅。单个订阅更新失败不会影响其他订阅。

![截图：启动时刷新订阅](images/user-guide/12-subscription-auto-refresh.png)

*截图建议：展示“设置 → 订阅设置”中的“启动时刷新订阅”开关。*

### 4.4 启用、停用或删除规则

1. 进入“设置 → 规则管理”。
2. 可通过规则名称或域名搜索，也可以按类型筛选。
3. 使用规则旁的开关启用或停用规则。
4. 点击规则的更多菜单，可进行置顶、登录或删除等操作。普通用户不需要进入“编辑规则”。
5. 如需一次处理多条规则，可进入批量管理后选择“启用”“停用”或“删除”。

停用规则后，该来源不会继续参与发现、搜索和阅读，但规则仍保留在本机。删除规则后无法恢复；如有需要，应先确认自己仍保存着规则文件或订阅地址。

## 5. 浏览与搜索内容

### 5.1 使用“发现”浏览

1. 点击底部的“发现”。
2. 从已启用的站点或规则中选择一个内容源。
3. 进入该站点后，选择分类或标签。
4. 上下滑动浏览内容；如支持分页，继续滑动可加载更多。
5. 点击感兴趣的作品进入详情页。

如果“发现”页没有站点，请先导入支持发现功能的规则。规则已经导入但仍不显示时，请到“设置 → 规则管理”确认该规则处于启用状态。

![截图：发现页站点列表](images/user-guide/14-discover-sources.png)

*截图建议：展示已有规则后的发现页及站点入口。*

*截图建议：展示进入某个站点后的分类和作品列表。*

### 5.2 使用“搜索”查找

1. 点击底部的“搜索”。
2. 在搜索框输入作品名、作者或来源关键词。
3. 点击“搜索”。
4. 在结果中选择作品并进入详情页。
5. 如果结果较多，可使用页面中的筛选功能缩小范围。

搜索结果来自当前已启用且支持搜索的规则。不同来源的速度和结果可能不同，请耐心等待。

![截图：搜索页](images/user-guide/16-search-page.png)

*截图建议：展示搜索输入框、搜索按钮和结果列表。*

### 5.3 搜不到内容时

依次检查：

1. 手机网络是否正常。
2. 是否已经导入规则或添加订阅。
3. “设置 → 规则管理”中的相关规则是否已启用。
4. 是否输入了过长或过于精确的关键词，可尝试只输入作品名的一部分。
5. 订阅是否需要刷新。
6. 单个来源是否暂时失效，可尝试其他来源。

## 6. 查看详情与开始阅读

1. 在发现或搜索结果中点击作品。
2. 详情页会显示封面、作品信息和章节目录。
3. 点击章节开始阅读或播放。
4. 使用“正序 / 倒序”调整目录顺序。
5. 页面右上角可收藏或取消收藏作品。
6. 详情页的更多操作中可能包含“刷新”“清理缓存”或“换源”。当目录未更新或加载异常时，可先尝试“刷新”。

![截图：作品详情页](images/user-guide/17-detail-page.png)

*截图建议：展示封面、收藏按钮、章节目录以及正序/倒序切换。*

“换源”会尝试在其他内容源中查找相同作品。如果没有其他可用规则或未找到匹配结果，该功能可能没有可选项。

## 8. 收藏与阅读历史

### 8.1 收藏作品

在作品详情页点击收藏图标。收藏成功后，可以在底部“收藏”页面的“收藏”分类中找到该作品。

收藏页支持搜索、分类筛选和排序。进入管理状态后，可以选择并删除多条收藏。

### 8.2 查看阅读历史

1. 点击底部的“收藏”。
2. 切换到“历史”。
3. 点击记录可继续阅读。
4. 进入管理状态后，可以删除选中的历史记录，或清空指定范围的记录。

清空历史记录不会删除收藏内容，但清空后无法恢复。

## 9. 离线下载

### 9.1 添加下载

在阅读页打开工具栏或更多菜单：

- 下载当前章节或当前话：选择“下载当前章”“下载当前话”或“下载此视频”。
- 批量下载：选择“批量下载”，再选择后续章节数量或自定义章节。
- 视频为 HLS 格式时，可能需要先选择下载清晰度，再点击“确认下载”。

下载时请保持网络稳定，并确保手机有足够存储空间。

![截图：阅读页下载入口](images/user-guide/22-download-entry.png)

*截图建议：展示小说、漫画或视频阅读页中的下载入口。*

### 9.2 管理下载

1. 进入“设置 → 我的下载”。
2. 在“已下载”中查看可离线打开的内容。
3. 在“下载中”中查看等待、进行中或失败的任务。
4. 对失败任务可按页面提示重试。
5. 进入管理状态后可以删除下载任务或已下载作品。

删除已下载内容会释放存储空间，删除后需要重新联网下载。

### 10.1 外观

进入“设置”，可选择：

- 跟随系统
- 浅色模式
- 深色模式

### 10.2 阅读设置

进入“设置 → 阅读设置”，可以调整字号、行高、页边距、阅读背景、漫画显示方式和视频自动播放等选项。

- 查看章节、图片、视频和网站图标的缓存占用；
- 设置浏览缓存上限；
- 开启或关闭章节、图片、视频和网站图标缓存；
- 清理章节缓存、图片缓存或全部浏览缓存。

“清理全部浏览缓存”不会删除“我的下载”中的离线内容。缓存清理后，重新打开内容时可能需要再次联网加载。

## 12. 常见问题

### 12.1 导入时提示格式不对

请确认粘贴的是完整的规则内容、HTTP/HTTPS 规则网址、`ikan://` 或 `eso://` 分享链接。不要粘贴普通作品页面地址，也不要漏掉内容开头或结尾。

### 12.2 添加订阅失败

可能原因包括：

- 订阅地址不完整或已经添加；
- 网络暂时不可用；
- 订阅发布者已更换地址；
- 远程内容不是 App 支持的订阅格式。

请先重新复制完整地址，再联系订阅发布者确认地址是否仍有效。

### 12.3 订阅更新后规则发生变化

订阅规则由远程发布者维护，刷新后会以最新订阅内容为准。如果希望保留一份不会自动变化的规则，可另行导入为本地规则。

### 12.4 已导入规则，但发现页没有内容

该规则可能已停用、不支持发现功能或内容站点暂时不可用。请到“设置 → 规则管理”确认规则已启用，然后尝试“搜索”功能或刷新订阅。

### 12.5 章节、图片或视频加载失败

请依次尝试：

1. 检查网络连接；
2. 返回后重新打开；
3. 使用页面中的“重新加载”或“刷新”；
4. 清理当前章节缓存后重试；
5. 更新订阅；
6. 使用“换源”或尝试其他内容源。

### 12.6 内容源要求登录

进入“设置 → 规则管理”，打开对应规则的更多菜单，选择“登录规则”或“重新登录”。在打开的登录页完成网站登录后返回 App。

请仅在你信任的内容源登录，不要向他人发送账号、密码、验证码或登录后的分享内容。

### 12.7 换手机后如何恢复

本地规则不会因为重新安装 App 自动恢复。换机或卸载前，可打开导入窗口并使用“导出备份”保存规则备份，同时妥善保存自己的订阅地址。收藏、历史和下载内容是否可迁移，请以当前发布版本提供的备份能力为准。
